<p>谈住宅 IP 的成本，最容易犯的错是只比单价。一条线月费八十还是两百，放在三个月、五个人的尺度上看，差异远小于交接混乱和反复重开带来的损耗。这篇把成本拆成四笔——线路、环境、交接、故障——每笔给计算口径和一个可代入的例子，最后汇总成一张三个月总账。文中价格为经验区间，仅供参考。</p>
<h2>一、把成本拆成四笔再看总价</h2>
<p>不拆账的时候，所有支出都归到「代理费」一栏，看起来只占预算的一小块。拆开之后常会发现，真正的支出在别的地方。</p>
<h3>为什么要这么拆</h3>
<p>因为四笔钱的决策人不同、优化空间不同。线路单价由服务商定，你能做的是选档；环境成本由自己定，多做一步配置就省一次重登；交接和故障属于损耗，靠流程压下来。混在一起谈，只能砍单价，砍到线路质量下降，反而推高后两笔。</p>
<h3>四笔的大致比例</h3>
<p>五个人、十五个号的规模下，线路约占六成，环境约一成，交接约两成，故障重开约一成。规模越大，交接与故障的占比越容易走高，所以这两笔值得单独盯。</p>

<h2>二、第一笔：线路单价与复用</h2>
<p>线路是唯一能直接比价的项，但也最容易被比错。同一个「住宅 IP」标签下，独享与共享、固定与轮换、原生与转售，价格能差三倍。</p>
<h3>单价差在哪</h3>
<p>三处：一是独享程度，一条线只服务一人，价格自然高；二是归属纯净度，双 ISP 同源、ASN 为运营商的线路更贵；三是服务承诺，承诺三十分钟换线的产品，单价里含了运维成本。三项都要问清，不能只问最后那个数字。</p>
<h3>复用率怎么换成钱</h3>
<p>一条独享线如果只服务一个号，每天用两小时，等于八成时间闲置。合理做法是把使用时段排满：上午给 A 组，下午给 B 组，前提是两个号不在同一时间操作。这样一条线能覆盖两个号，单价折半。但要注意，错峰不等于共用，两个号同时在线就是撞线。</p>

<h2>三、第二笔：环境与设备成本</h2>
<p>环境成本主要是工时，不是硬件。同一台机器跑十个环境很常见，真正花时间的是每个环境的参数对齐和后续维护。</p>
<h3>一台机器能跑几个环境</h3>
<p>按内存算：每个浏览器环境常驻约 300 到 600 MB，十六 G 内存的机器跑八到十个比较稳，再多就开始互相拖慢。比起堆硬件，更划算的是把环境做成模板，新号导入模板后只改时区语言和代理三项。</p>

<h2>四、第三笔交接与第四笔故障</h2>
<p>这两笔都不出现在任何报价单上，但每个月都在发生。算法很简单：次数乘单次工时，再乘人力成本。</p>
<h3>交接损耗的计算口径</h3>
<p>一次完整交接，如果没有清单，平均要花两到四小时：找线路、核环境、试登录、排查历史异常。有清单的话压到二十分钟以内。按每月两次交接、人力成本每小时八十元算，一年差出三千到七千元，这笔钱足够多买好几条独享线。</p>
<h3>故障重开的期望成本</h3>
<p>一次账号异常到恢复，常见是半天到两天。期望成本等于发生概率乘停摆时长乘时均产值。把概率从每月一次压到每季一次，收益往往超过线路降档省下的钱。</p>

<h2>常见问答</h2>
<h3>时均产值怎么估才不离谱？</h3>
<p>答：用月度毛利除以有效工时，得出一个粗值即可，不必精确到角。关键是让四笔成本用同一个单位比较，只要能排序，方向就不会错。</p>
<h3>共享池真的不能用于核心号吗？</h3>
<p>答：不是绝对不能，是不划算。共享池的地址复用率高，历史记录杂，一旦出问题排查成本高。核心号用它，省下的线路费通常会被故障成本吃掉。</p>
<h3>备用线路要长期挂着吗？</h3>
<p>答：挂一到两条即可，不必全量备份。备用线只在故障时短时接管，平时闲置。也可以选择按天计费的临时线路，出事时再开，成本更低。</p>
<h3>交接损耗能不能完全消掉？</h3>
<p>答：消不掉但能压到很低。清单、编号、记录三样齐了，单次交接能压到二十分钟以内。剩下那部分属于正常沟通成本，不必追求归零。</p>
